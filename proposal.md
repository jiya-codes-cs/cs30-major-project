# Major Project Proposal

## Description for Major Project
- This project is a webcam-based hand gesture interface for creating and manipulating a dynamic on-screen display. The user's hand movements control the position of a circle and the letters surrounding it. A specific hand gesture can be used to select and "lock" a letter. Once a letter is locked, the user tries to guess the word that the clue describes and when the user is done the next level pops up.
